# 此刻 · 时间的方向

原创无声横版短片，1920 × 1080（16:9），30 fps，74 秒，11 个镜头。画面以原生 SVG 绘制，采用深黑、冷白和琥珀光，配本地宋体。无外部视频素材、音乐或旁白。

## 预览

在本目录运行 `npm run studio`，打开 <http://localhost:3417/TimeArrow>，按空格播放。每个镜头也可在 Studio 的 Cinema-Scenes 目录单独打开。

本项目使用独立目录、独立依赖副本和 3417 端口，不改动其他会话的视频项目。横版源码位于 `src/landscape/`；早期竖版保存在 `src/Root.vertical.tsx` 及原有场景文件中，没有注册到当前 Studio。

## 推荐文案

时间，为什么只朝一个方向走？

杯子碎了，不会自己拼回去。
烟一散，几乎不会重聚。
恒星燃尽，出发的光还在远去。

这不是惩罚。是概率。
整齐的摆法太少。
散乱的可能，太多。
于是，世界更容易散开。

可太阳还在，把氢拧成光。
树还在，把光刻成年轮。
你还在，把热散向身外。
用流动的能量，维持自己。

秩序从不免费。
总有别处，替它付账。
局部更有序，周围更分散。

时间的箭头，指向整体熵增。

所以此刻，才值得被记住。

## 画面与节奏

| 开始 | 时长 | 画面 |
| --- | --- | --- |
| 0s | 6s | 时间的丝线缓慢拉开，提出问题 |
| 6s | 7s | 白瓷微距、下落、撞击、曲面碎片落地 |
| 13s | 6s | 多层薄烟丝扩大与扩散 |
| 19s | 6s | 光点向深空散开 |
| 25s | 9s | 晶格排列过渡为更多散乱可能 |
| 34s | 7s | 太阳微距：细颗粒、活动区、局部开放日珥 |
| 41s | 6s | 偏心年轮、木孔与裂隙，新光沿圈留下痕迹 |
| 47s | 7s | 侧脸雕塑、能量进入和热量散开 |
| 54s | 7s | 细光织成暂时有序的结构，周围光粒离开 |
| 61s | 6s | 单向远去的光路，说明整体熵增 |
| 67s | 7s | 居中“此刻”与结尾文案，最终淡出 |

以上时长已计算相邻场景 0.6 秒交叉淡化；自然场景长度可在 `Cinema.tsx` 独立编辑。

## 科学边界

讨论的是热力学时间箭头，熵不减的条件明确写在画面上：在孤立系统中，整体熵不减。太阳、树木和人体交换能量，允许局部维持或增加秩序。“整齐/散乱”是微观状态数量的诗化表达。宏观逆过程的概率极低，而非严格不可能。

## 验证

`npm run check` 检查 TypeScript。`qa/landscape/` 存放 16:9 的关键帧和画面速览，包含杯子完整、撞击前、碎裂上抛与落地四种状态。动画全部由 Remotion 视频帧驱动，无实时随机或 CSS 动画。

本地字体从本机 Songti SC 字体集合提取 Regular 字重用于预览。
