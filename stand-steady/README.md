# 站稳

原创植物意象短片，28 秒，1920 × 1080，30 fps，16:9，完全无声。

## 视觉

深青绿晨雾、暖金侧光、细长草叶、露珠、低对比远景与缓慢风动。所有画面以确定性 Canvas 绘制，不使用素材视频。草叶通过逐段切线积分弯曲，保留叶片弧长、固定根部。字幕以宋体、固定留白与渐显节奏呈现。

## 启动

```sh
npm install
npm run studio
```

本项目只在 `stand-steady` 内工作，预览使用独立端口 3328。依赖已复制到此目录，不向其他项目写入。

## 文案

风越强，草越贴近地面。

弯下去，它承受的风就小一些。

等风过去，它又慢慢抬起头。

稳定，需要调整。

我们也一样。

环境变了，可以换一种姿态。

守住自己的方向，不必守住每一个动作。

## 编辑与导出

- `src/StandSteady.tsx`：字幕、时间与风的节奏。
- `src/grass.ts`：草叶、种穗、露珠与形变。
- `src/scene.ts`：环境、柔光、景深、颗粒。
- `src/Root.tsx`：尺寸、帧率和时长。

```sh
npm run typecheck
npm run render
```

成片输出到 `output/stand-steady.mp4`。本地字体使用 macOS 的 Songti SC。
