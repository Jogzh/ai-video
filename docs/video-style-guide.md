# 视频视觉与动态设计规范

适用范围：本仓库后续新建或调整的视频，尤其是知识短片、视觉叙事和 Remotion 动画。目标是让观众容易理解、愿意观看，让文字与画面有自然的关系。

“优雅”来自明确的主次、合适的留白、准确的时机和克制的运动。每个镜头都应回答三个问题：这一刻要表达什么？观众先看哪里？为什么需要这次变化？

本规范给出设计原则和验收方法，不规定所有视频使用相同的字体、位置或动画。具体风格服从内容与用户要求。

## 1. 从内容开始设计

- 一条视频围绕一个核心问题展开，每个镜头承担一个清楚的叙事任务：提出问题、观察现象、解释机制、比较、转折或收束。
- 在编码前写简短分镜，说明信息与画面的关系。不要先套模板，再把句子填进去。
- 知识内容先核实事实和适用条件。诗意表达可以帮助理解，但不能替代机制解释，或把概率极低说成绝对不可能。
- 画面要承担信息。删掉文案后，如果所有镜头只是同一种背景，应重新检查主体与视觉解释。
- 无声视频必须通过画面和文字形成完整表达；有旁白的视频应让画面补充旁白，减少同时竞争的长段文字。

分镜至少包含这些字段，简单项目可直接写成表格：

| 镜头 / 时间 | 叙事任务 | 主体与视觉重心 | 文案及阅读顺序 | 图文关系与动作 | 完整阅读停留 |
| --- | --- | --- | --- | --- | --- |
| 开场 | 让人理解要问什么 | 一个明确的现象或物体 | 问题中的核心词优先 | 文字靠近问题发生的位置，主体先提供线索 | 问题可读完后再推进 |
| 解释 | 展示变化的原因 | 变化本身或前后对比 | 短句、标签或关键词 | 标注与对象同步，关键字随机制变化 | 留出看图与读字的时间 |
| 结尾 | 收束理解或情绪 | 减少元素、集中重心 | 一个结论 | 动作逐渐停下，最后一个信息获得停顿 | 结论完整可见后再离场 |

## 2. 构图随叙事变化

每场先安排主体、视线方向和留白，再安放文字。文字的位置可以由物体、运动轨迹、图表或镜头留白决定。

- 全片统一视觉语言，但根据叙事切换重心、景别、图文关系和信息密度。
- 可以采用居中聚焦、两侧对照、沿路径展开、局部标注、文字主导或画面主导等构图。选择要有原因，不轮流套用版式。
- 连续镜头若采用相同布局，应形成连续观察或比较的意义。只有背景和句子变化、关系完全不变时，需要重新设计。
- 在问题、机制揭示、转折和结论等节点安排视觉变化；平静或观察段落允许保持稳定。
- 文字和画面共同构图。只挪动文字，而主体始终锁在同一侧，通常仍会有模板感。
- 一个时刻有一个主要视觉焦点。高亮、大字、快速运动和明亮主体不要同时争夺注意力。

构图应在目标画幅上设计。需交付多个画幅时，分别检查图文关系并按需要重排，不能默认只裁切或缩放成片。用画面比例、对齐关系和主体边界确定位置，再落实到像素；固定坐标是实现手段，不能成为全片的设计理由。

## 3. 区分字幕与叙事文字

| 文字角色 | 布局原则 | 动态原则 |
| --- | --- | --- |
| 连续字幕 | 稳定、易找、避开平台遮挡，按语义断句 | 跟随说话节奏，优先保证连续阅读 |
| 标题与问题 | 根据镜头重心安排，建立第一阅读层级 | 入场引导视线，读完之前不急着离场 |
| 关键词与结论 | 用字号、位置、颜色或留白强调关键关系 | 只在有意义的节点变化，完整显现后停留 |
| 物体标签与图表标注 | 靠近被解释的对象，关系明确 | 必要时跟随对象、数值或状态变化 |
| 次要说明 | 降低视觉权重，但仍可读 | 避免抢占主要信息的入场时机 |

- 每屏控制文字量，长句先编辑，再决定换行和布局。
- 主次用少量明确的层级建立。不要把每个词都放大、变色或单独动画。
- 断句顺着语义，避免把关键短语拆散，或为了对齐强行凑成相同字数。
- 文字不能遮住需要观察的动作、人物表情、数据或物体细节；标签确需覆盖时，要让关系清楚。
- 英文小标题、章节编号、装饰线等只在有用途时出现，不把装饰当作精致感。
- 字体服务内容：科学解释需要清晰，情绪叙事可以更有性格。字体数量和字重保持克制，正文与数字的风格协调。
- 最长文案、标点和数值变化都要检查。`whiteSpace: nowrap` 不能代替宽度测量和合理断行。

## 4. 让运动表达关系

先描述动作的含义，再选动画。优先让主体动作、镜头变化或一个关键词承担表达，不默认给每个字加特效。

| 内容关系 | 可选表达 | 需要避免 |
| --- | --- | --- |
| 扩散 | 主体散开，标签距离适度增大 | 整句话散到无法阅读 |
| 聚合、形成秩序 | 对象或关键词从分散状态收拢 | 无关元素同时飞入 |
| 流动、方向 | 沿路径推进、标注跟随 | 所有文字始终漂移 |
| 生长、恢复 | 轮廓揭示、向上展开或逐步积累 | 任意弹跳代替真实变化 |
| 对比、因果 | 先展示条件，再出现结果 | 前因后果同时挤满屏幕 |
| 停顿、结论 | 收敛运动、减少信息、稳定定格 | 到最后仍持续加速和转场 |

- 动作要有起点、过程和落点。入场后通常进入稳定阅读，不持续摇晃正文。
- 运动方向、速度和缓动保持风格一致；镜头间可以变化，但不能每场随机换一种效果。
- 位移、缩放、旋转、透明度和模糊按需要选择。简单变化有效时，就保持简单。
- 缓慢推进、视差或光线变化用于增强空间和情绪，避免所有镜头机械地做同一种缩放。
- “碎裂”“弯曲”等动作要保持物体结构、受力和空间关系可信；文字动画与画面事件对齐。
- 避免为制造动态而给所有镜头增加随机运动、弹簧、粒子或炫技转场。

## 5. 节奏包含阅读与停顿

镜头时长由信息量、画面动作和情绪决定。节奏服务内容，必要时安排快慢变化和让观众自己观察的空白。短片或单镜头不强求完整的段落结构。

- 把“入场时间”和“完整可读时间”分开计算。文字清晰、完整且达到稳定可读状态之后，才开始完整阅读停留。
- 中文可先按每秒约 5–7 个字估算阅读时间，再根据术语、图表和推理复杂度放慢；这个数值只是初稿参考。
- 观众需要同时看图和读字时，要额外留时间。不能因为旁白已说完，就认为画面已看懂。
- 逐字入场会消耗阅读时间，短镜头优先采用整词或整句。解释句不要反复出现、消失，迫使观众追字。
- 结论显现后先停留，再淡出。淡出和转场重叠的时间不算完整停留。
- 有声视频检查语音、字幕、画面事件与音效的同步。音乐不掩盖旁白，音效强调有意义的事件。
- 无声视频用动作变化、画面切换和停顿建立节奏；允许安静，但避免所有段落具有同一种渐显节拍。
- 转场连接相邻镜头的意义。能直接切换时可以直接切换；叠化期间也要检查图文重叠。

## 6. 风格统一与组件复用

每条视频先确定少量视觉约定：字体角色、色彩关系、对比度、线条或材质、运动速度、空间感。具体值来自内容与风格方向，不沿用上一个视频的值作为默认审美。

- 复用颜色、字体、间距尺度、缓动和基本图形，保持整体一致。
- 场景组件负责具体构图、主体位置、文字层级和时间安排。
- 通用文字组件可以提供测量、入场和强调能力，但不要强制所有场景使用同一正文位置、字号、行数与动效。
- 位置、对齐、宽度、运动方向和延迟需要能在场景中覆盖；提供默认值时，要明确其适用角色。
- 不同风格的视频可以共用技术基础，不应被同一外观模板锁定。

## 7. Remotion 实现约定

- 所有视觉变化由视频帧驱动，使用 `useCurrentFrame()`、`useVideoConfig()` 与明确的时间范围。拖动时间轴、反向跳帧和渲染应得到一致结果。
- 随机粒子和纹理使用固定种子。避免依赖 `Math.random()`、实时时钟、CSS animation 或计时器决定画面状态。
- 子场景以局部时间组织动作，全片安排镜头长度与转场；把转场重叠计入总时长。
- 字体和素材可靠加载后再捕获画面。字体子集要覆盖实际文案、标点和数字，不能依赖开发机器恰好有某个字体。
- 明确 SVG、Canvas 和 DOM 的尺寸、裁切及图层边界。移动、缩放主体后重新检查边缘，避免提前裁切或遮挡。
- 先保持预览流畅，再增加昂贵效果。缓存静态几何和纹理，减少每帧无意义的重建。
- 使用相关 Remotion 技能落实 API 和预览方式；本规范负责设计要求，不替代工具文档。

## 8. 制作与验收流程

1. 完成核心问题、事实核验和简短分镜，写清图文关系与关键动作。
2. 先实现一个能代表风格的关键段，在预览中验证字体、构图、动作和阅读节奏，再扩展全片。常规设计选择直接推进，缺失的关键要求再向用户澄清。
3. 连续观看全片，检查信息顺序、快慢、段落关系和结尾；单帧好看不等于全片成立。
4. 抽查每场的入场、完整阅读、关键动作、离场，以及相邻镜头的转场中点。长句、最大位移和最亮背景额外检查。
5. 在目标观看尺寸检查可读性与平台 UI 安全区。安全边距按实际发布渠道确定，正文、关键词和重要主体都要避开遮挡。
6. 对关键段检查跳帧与重复捕获的一致性。分别查看独立场景和整片中的同一时刻，排除整合后才出现的问题。
7. 运行与改动相关的类型、lint 等检查；视觉验收单独记录。工具不可用时说明缺失的验证，不把静态检查描述成视觉通过。
8. 交付源码、预览入口和简短设计说明。用户明确要求导出时再生成完整成片；截图与渲染产物按项目规则存放，提交前检查范围。

### 完成前自检

- [ ] 首屏能让观众理解问题或产生具体好奇。
- [ ] 每场都有叙事任务，画面确实承载信息。
- [ ] 连续镜头的构图选择有理由，不只是固定位置换文字。
- [ ] 主要焦点明确，正文、关键词和说明层级清楚。
- [ ] 文字与主体不冲突；所需交付画幅和目标平台安全区已检查。
- [ ] 动作表达内容，正文完整显现后能稳定读完。
- [ ] 转场没有叠字、遮挡、突跳或错误裁切。
- [ ] 节奏与内容匹配；需要观察、转折或收束的地方获得了合适的停顿与变化。
- [ ] 文案、字形、事实边界和音画同步已检查。
- [ ] 技术检查与视觉检查的结果分别说明。

若只是把固定字幕换成到处移动的字幕，仍不算完成设计。应回到分镜，重新确定信息、主体与观看顺序的关系。
