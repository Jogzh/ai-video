# 单条内容 Brief 模板

## 基本信息

- 题目：
- 支柱：AI 机制 / 技术与日常 / 反常识实验
- 目标观众：
- 核心知识点（一句话）：
- 事实来源/待核验链接：

## 脚本骨架

- 0–3 秒：一句具体问题或反常识结果
- 3–10 秒：生活化例子
- 10–30 秒：只解释一个机制
- 30–40 秒：给观众一个判断/动作
- 结尾：下一条承接或评论区问题

## 视觉与分镜

制作前检查：构图是否顺着内容变化，动作是否有表达目的，正文是否有稳定阅读时间，结尾是否获得停顿。

## 发布检查

- 标题是否以 `Vibe知识大赏` 开头并包含具体问题
- 话题是否使用活动页显示的准确词
- 是否有可核验来源
- 是否只讲一个核心结论
- 首帧是否不依赖声音也能看懂
- 是否避免夸大、伪科学、无依据收益承诺和引流营销
