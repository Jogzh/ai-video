# 工具与工程准备

## 当前已完成

- Git 仓库已初始化，默认分支为 `main`。
- FFmpeg 已通过 Homebrew 安装，可用于后续转码、拼接、抽帧和音频处理。
- 已建立 `assets/`、`src/`、`scripts/`、`docs/`、`output/` 目录。
- 已加入 `scripts/check_env.sh`，用于检查基础环境。

## Remotion 是否现在需要

现在不需要。当前阶段的瓶颈是选题、内容验证和账号承接，Remotion 只会在确定需要以下能力时再引入：

- 用 React/TypeScript 生成大量结构统一的视频
- 字幕、图表、卡片、进度条需要参数化批量渲染
- 需要用代码保证每条视频的尺寸、字体和节奏一致

如果后续采用 Remotion，建议在首轮 6 条内容中验证出固定模板后再安装，避免先引入依赖和渲染复杂度。届时再决定使用 Remotion、纯 FFmpeg，还是剪辑软件模板。

## 后续可选工具

- FFmpeg：确定保留，用于媒体基础处理。
- 字幕生成：先用脚本/字幕文件验证，不急于绑定具体 SDK。
- 图像生成：仅在选题需要原创插图或背景时使用。
- Remotion：等内容模板稳定后再评估。
